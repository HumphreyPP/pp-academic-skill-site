安装方法

中文：下载 zip 后，把里面的 skill 文件夹放到自己的 Codex skills 目录。English: Download a zip, then place the extracted skill folder into your Codex skills directory.

Windows 推荐步骤

  1. 下载单个 skill zip 或完整 bundle。
  2. 解压后确认文件夹内有 SKILL.md。
  3. 把 skill 文件夹复制到 %USERPROFILE%\.codex\skills。
  4. 重启 Codex，或新开一个对话。
如果使用完整 bundle，解压后会看到多个 skill 文件夹，把这些文件夹一起复制进 .codex\skills 即可。公开下载包已排除 PDF 等不适合直接公开分发的资源。

注意事项

  1. 标记为 Needs local setup 的 skill 依赖 Zotero、Obsidian 或本机路径，需要按自己的电脑改配置。
  2. 如果只是想改论文，优先下载 diagnostic 类 skill。
  3. 如果想复刻 Humph 的文献学习流水线，下载 core pipeline 类 skill。
  4. 如果下载后 Codex 没识别，检查是否多套了一层文件夹。
